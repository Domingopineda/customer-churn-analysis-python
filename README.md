# 📊 Customer Churn Analysis with Python

## Project Overview

Customer churn is one of the most important business metrics for subscription-based companies. Losing existing customers reduces revenue and increases acquisition costs.

This project analyzes customer behavior to identify the factors most associated with customer churn using Python and exploratory data analysis (EDA).

---

## Business Questions

The analysis answers the following business questions:

1. What percentage of customers churn?
2. Do customers who complain churn more often?
3. Does subscription length affect churn?
4. Do higher charge amounts increase churn?
5. Which age group has the highest churn rate?
6. Does customer value influence churn?
7. Do customers with higher service usage churn less?
8. Which customer profile is most likely to churn?
